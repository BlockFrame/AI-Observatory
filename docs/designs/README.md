# Design specifications

Design specifications translate a ready user story into a reviewable implementation contract before high-risk or cross-cutting work begins. Use one for changes that span components, alter a public contract, affect paid calls, require migration, or need staged rollout.

## Index

No active specifications have been committed yet. Start from [the template](template.md), name files `YYYY-MM-DD-concise-title.md`, and link the owning GitHub issue and any ADR.

Specifications are versioned implementation records, not an alternative backlog. Status, priority, and delivery ownership remain in the GitHub AIDLC Project.
