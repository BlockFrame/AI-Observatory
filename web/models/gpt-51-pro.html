GPT-5.1 Pro

business Maker: OpenAI account_tree Family: GPT-5

// Overview

GPT-5.1 Pro was OpenAI's highest-compute consumer reasoning model, released on November 19, 2025 as part of the GPT-5.1 family. It rolled out inside ChatGPT and replaced GPT-5 Pro in the model picker. Like the rest of the GPT Pro line, GPT-5.1 Pro is the 'thinking-first' option built for hard problems: it spends extended, parallel test-time compute to produce the most careful and reliable answers OpenAI offered at the time, trading speed for quality.

Unlike the broader GPT-5.1 release, GPT-5.1 Pro was a ChatGPT product feature rather than a published API model. It was available to ChatGPT Pro and Business subscribers through the model picker, with the Pro plan priced at $200 per month. At launch OpenAI did not ship a separate gpt-5.1-pro API endpoint; developers wanting Pro-grade compute used the existing GPT-5 Pro API line, while GPT-5.1 itself shipped to the API as the standard model. Third-party trackers noted the GPT-5.1 Pro API had not been officially released.

GPT-5.1 Pro had an unusually short life at the top. OpenAI released the full GPT-5.2 family on December 11, 2025 — under a month later — and GPT-5.2 Pro took over as the smartest, most trustworthy ChatGPT option for difficult questions. GPT-5.1 Pro is therefore best understood as a brief, transitional step between GPT-5 Pro and GPT-5.2 Pro during OpenAI's rapid late-2025 release cadence.

// FAQ

What was GPT-5.1 Pro?

GPT-5.1 Pro was OpenAI's highest-compute reasoning model in the GPT-5.1 family, released on November 19, 2025. It was the 'thinking-first' ChatGPT option that used extended, parallel test-time compute to give the most careful and reliable answers for hard problems, replacing GPT-5 Pro in the model picker.

Could you use GPT-5.1 Pro through the API?

Not at launch. GPT-5.1 Pro was a ChatGPT product feature for Pro and Business subscribers, not a published API model. OpenAI shipped standard GPT-5.1 to the API, but third-party trackers noted that a dedicated GPT-5.1 Pro API endpoint had not been officially released.

How much did GPT-5.1 Pro cost?

Access was through the ChatGPT Pro subscription at $200 per month (it was also available to Business users). OpenAI did not publish separate per-token API pricing for GPT-5.1 Pro; the underlying GPT-5.1 API model was priced at $1.25 per million input tokens and $10 per million output tokens.

Is GPT-5.1 Pro still available?

No. GPT-5.1 Pro was superseded quickly: OpenAI released the GPT-5.2 family on December 11, 2025, under a month after launch, and GPT-5.2 Pro took over as the top ChatGPT reasoning model.
